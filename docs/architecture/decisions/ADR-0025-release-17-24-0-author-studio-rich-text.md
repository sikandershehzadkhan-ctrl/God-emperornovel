# ADR-0025: Release Author Studio rich text as Imperial Novel 17.24.0

- **Status:** Proposed
- **Date:** 2026-11-22
- **Owners:** Architecture contracts, frontend runtime, Worker release

## Context

The Author Studio Tiptap editor and structured chapter reader have been merged into the source branch. The editor uses a new route-only JavaScript bundle and stylesheet. The existing service worker precaches versioned application assets under a release-specific cache key.

Deploying changed application JavaScript under the old 17.23.0 URL risks stale browser and offline cache behavior.

## Decision

Bump the application release to 17.24.0 and create matching versioned copies of the application entry, stylesheet assets, rich-text editor stylesheet, and PWA manifest. Update the HTML entry point, service-worker cache key and precache list, Wrangler APP_VERSION, package manifest and npm lockfile root version together.

The editor JavaScript bundle remains generated by the build and is dynamically loaded only in Author Studio. It is not added to the homepage's core precache list.

## Consequences

- The browser receives new cache-busted asset URLs.
- Existing 17.23.0 assets remain available for already-open clients and cached pages.
- The editor bundle remains lazy-loaded and does not increase the initial reader/homepage JavaScript payload.
- This release PR does not run the production deployment workflow or mutate D1.
